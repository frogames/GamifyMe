## Inscription et Connexion

### Inscription
Pour vous inscrire sur GamifyMe, vous devez utiliser le lien d'inscription spécifique fourni par votre établissement (école, entreprise, etc.). Ce lien contient un identifiant unique qui vous rattachera automatiquement à la bonne organisation.

Le formulaire d'inscription vous demandera les informations suivantes :
- **Prénom**
- **Nom d'utilisateur** (doit être unique)
- **Email**
- **Mot de passe**

Une fois le formulaire validé, un email de confirmation vous sera envoyé. Cliquez sur le lien dans l'email pour activer votre compte.

### Connexion
Rendez-vous sur la page de connexion, entrez votre email et votre mot de passe pour accéder à votre espace personnel.

---

## Accueil

Dès votre connexion, vous arrivez sur votre page d'accueil personnalisée. Elle vous offre une vue d'ensemble et un accès rapide aux fonctionnalités principales :

- **Mon Pass** : Accès direct à votre QR code personnel.
- **Objectifs** : Voir le nombre d'objectifs disponibles à réaliser.
- **Boutique** : Voir le nombre d'articles disponibles à l'achat.
- **Inventaire** : Consulter vos objets acquis.
- **Groupes** : Rejoindre ou gérer votre groupe.
- **Classements** : Voir votre position par rapport aux autres joueurs.

---

## Mon Pass (QR Code)

Cette section est **essentielle**. Elle affiche votre QR Code personnel unique.

**À quoi ça sert ?**
Ce QR Code est votre carte d'identité dans le jeu. Il doit être présenté aux membres du staff (professeurs, managers, etc.) pour :
- **Valider un objectif** : Le staff scanne votre QR code pour confirmer que vous avez réalisé une tâche et vous attribuer des points.
- **Récupérer une commande** : Le staff scanne votre code pour valider la remise d'un objet acheté en boutique.

*Astuce : Vous pouvez faire une capture d'écran de votre QR Code pour l'avoir toujours à portée de main, même sans connexion internet.*

---

## Objectifs

C'est ici que vous gagnez des points !

La page "Objectifs" liste toutes les missions disponibles pour vous. Chaque objectif affiche :
- Le titre et la description de la tâche.
- La récompense en points (crédits).

**Comment valider un objectif ?**
Une fois la tâche accomplie, allez voir un membre du staff autorisé. Présentez-lui votre **Pass (QR Code)**. Il le scannera pour valider l'objectif et vos points seront instantanément crédités sur votre compte.

---

## Boutique

La boutique est l'endroit où vous pouvez dépenser vos points durement gagnés.

Vous y trouverez la liste des articles disponibles avec leur coût en points et le stock restant.

**Comment acheter ?**
1. Cliquez sur l'article qui vous intéresse.
2. Si vous avez assez de points, cliquez sur le bouton d'achat.
3. Vos points sont déduits et l'article est ajouté à votre **Inventaire**.

---

## Inventaire

L'inventaire regroupe tout ce que vous avez acheté ou gagné.

Pour récupérer physiquement un objet acheté (par exemple un goodie, un ticket repas, etc.), présentez-vous au point de retrait indiqué par votre établissement. Montrez votre **Pass (QR Code)** au staff, qui le scannera pour valider la remise de l'objet. L'objet sera alors marqué comme "consommé" ou "livré" dans votre inventaire.

---

## Groupes

GamifyMe est aussi une aventure collective !

- **Rejoindre un groupe** : Si vous avez un code d'invitation, vous pouvez rejoindre un groupe existant.
- **Voir mon groupe** : Une fois dans un groupe, vous pouvez voir les autres membres.

Appartenir à un groupe peut être nécessaire pour certains objectifs collectifs ou simplement pour comparer vos scores entre amis.

---

## Classements

Mesurez-vous aux autres utilisateurs !

La page "Classements" affiche les meilleurs scores de l'établissement. Vous pouvez voir votre rang et essayer de grimper dans le classement en complétant plus d'objectifs.
